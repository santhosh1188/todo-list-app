# 📝 Todo List App

A simple and interactive **Todo List Web Application** built with **React.js**.  
This app allows users to **add, edit, and delete tasks**, with persistent storage using **LocalStorage**.  

---

## ✨ Features
- ➕ Add new tasks  
- ✏️ Edit existing tasks  
- ❌ Delete tasks  
- 💾 Data persistence with LocalStorage  
- 📱 Responsive design for mobile and desktop  

---

## 🛠️ Tech Stack
- **Frontend:** React.js, HTML, CSS, JavaScript  
- **State Management:** React Hooks (`useState`, `useEffect`)  
- **Storage:** LocalStorage
